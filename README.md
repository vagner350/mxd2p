# Loja MXD20 — maxd20.com.br

Loja do Tônico MXD20 Barbudom com a mesma base da amazole.store (catálogo pela API pública do
Hostinger Ecommerce, checkout próprio com Appmax: Pix, cartão e boleto), na identidade preto e amarelo.

- `instalar.php` monta o site no servidor: copia a base da amazole.store, aplica `patches.php`
  e a troca de marca/cores, e coloca por cima os arquivos de `site/`.
- Loja no Hostinger Ecommerce: store_01M61B38SQHHHJ5MY4E72HDENH, canal scha_01M61B38TG9Y250JW4V4PNZEK1.
